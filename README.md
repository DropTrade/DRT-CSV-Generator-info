# DRT CSV Generator

Prywatna aplikacja firmy **DROP TRADE OLEH PUTAS** przeznaczona do przygotowywania danych produktów oraz plików CSV dla ofert Allegro.

Aplikacja korzysta z Allegro REST API w celu:

- pobierania aktualnych kategorii Allegro,
- pobierania parametrów i ich dostępnych wartości,
- odczytu danych ofert po autoryzacji właściciela konta,
- przygotowywania danych do plików CSV.

Aplikacja jest wykorzystywana wyłącznie na potrzeby własne firmy.
